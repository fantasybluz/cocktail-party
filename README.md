# 7-11 調酒拉霸機

像素風的調酒拉霸機。三個轉輪分別是「基酒、材料一、材料二」，品項都是 7-11 買得到的東西。
每次轉出一杯現成酒譜，附上比例、口感，以及估算的酒感、甜度、氣泡。

遊戲本身就是一個 `index.html`（樣式、程式、像素字型都內嵌在裡面），不需要網路也能玩。

## 玩法

- 按 **SPIN** 或拉右邊的拉桿
- 點轉輪可以**鎖定**（例如家裡已經有威士忌），下次只會轉出用那個品項的酒譜
- 鎖定的組合沒有現成酒譜時，會出「實驗組合」，比例和口感自動組出來
- 轉完可以按「分享到 LINE」把酒譜傳到聊天室

## 在 LINE 使用

網址：https://fantasybluz.github.io/711-alcohol-slot-machine/

把網址貼到聊天室，大家點了會直接在 LINE 內建瀏覽器打開。
直接傳 `.html` 檔不行，LINE 會自動壓成 zip。

- 部署：GitHub Pages，推到 `main` 就會更新
- `og.png`：貼連結時聊天室顯示的預覽圖（1200x630），`<head>` 的 `og:image` 指向它
- 用網址打開時，分享到 LINE 的訊息會附上連結；用檔案打開時不附（本機路徑別人點不到）

## 修改內容

都在 `index.html` 最下面的 `<script>` 裡：

| 要改的東西 | 位置 |
|---|---|
| 轉輪品項（名稱、濃度、甜度、氣泡、顏色） | `BASES`、`MIXERS`、`ACCENTS` |
| 酒譜（組合、比例、口感、標籤） | `RECIPES` |
| 品項的像素圖樣（16x16） | `SPRITES` |
| 轉動時間 | `SPIN_DURATIONS_MS` |

酒譜裡的品名要和轉輪品項的名稱一致，打錯字時瀏覽器 console 會報錯。

酒譜整理自網路上的超商調酒文章，標「創意」的是自己搭的。各門市進貨不同，大店品項比較齊。
