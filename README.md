# 超商調酒拉霸機

像素風的聚會小工具，分兩個頁面（底部切換）：

- **調酒拉霸機**：三個轉輪「基酒、材料一、材料二」，品項都是超商（以 7-11 為主）買得到的東西。
  每次轉出一杯現成酒譜，附上比例、口感，以及估算的酒感、甜度、氣泡
- **喝酒遊戲**：8 種一支手機大家輪流操作的遊戲，輸了可以直接「去轉拉霸機」決定喝什麼

整個網站就是一個 `index.html`（樣式、程式、像素字型都內嵌在裡面）。

## 調酒拉霸機

- 按 **SPIN** 或拉右邊的拉桿
- 點轉輪可以**鎖定**（例如家裡已經有威士忌），下次只會轉出用那個品項的酒譜
- 鎖定的組合沒有現成酒譜時，會出「實驗組合」，比例和口感自動組出來
- 轉完可以按「分享到 LINE」把酒譜傳到聊天室

## 喝酒遊戲

| 遊戲 | 玩法 |
|---|---|
| 懲罰轉盤 | 跑燈停在哪格就照做，八格選項可以自己改（存在這支手機） |
| 數字炸彈 | 炸彈藏在 1～100，輪流猜，範圍越縮越小，猜中的人喝 |
| 開箱炸彈 | 箱子裡藏炸彈（箱子、炸彈數可調），開到的人喝 |
| 傳手機炸彈 | 隨機倒數，說出符合題目的答案再傳下去，爆炸時拿著的人喝 |
| 國王杯 | 抽牌照規則做，第四張 K 的人喝光國王杯 |
| 真心話大冒險 | 抽題目，不敢就喝 |
| 我從來沒有 | 做過題目上那件事的人喝 |
| 誰是臥底 | 傳手機看詞，描述後投票，找出拿到不同詞的人 |

每個頁面都有自己的網址（例如 `#spy`），LINE 和瀏覽器的上一頁也能用。

## 在 LINE 使用

網址：https://fantasybluz.github.io/711-alcohol-slot-machine/

把網址貼到聊天室，大家點了會直接在 LINE 內建瀏覽器打開。
直接傳 `.html` 檔不行，LINE 會自動壓成 zip。

- 部署：GitHub Pages，推到 `main` 就會更新
- `og.png`：貼連結時聊天室顯示的預覽圖（1200x630），`<head>` 的 `og:image` 指向它
- 用網址打開時，分享到 LINE 的訊息會附上連結；用檔案打開時不附（本機路徑別人點不到）

## 瀏覽人數

用 [GoatCounter](https://www.goatcounter.com) 記錄，還沒啟用。註冊後：

1. 把代碼填到 `index.html` 的 `GOATCOUNTER_CODE`
2. 在 GoatCounter 設定打開「Allow adding visitor counts on your website」

頁尾就會顯示「你是第 N 個酒鬼」（GoatCounter 的總數有最多四小時的快取，是大概的數字），
後台也看得到每個遊戲頁的瀏覽數。

## 修改內容

都在 `index.html` 最下面的 `<script>` 裡：

| 要改的東西 | 位置 |
|---|---|
| 轉輪品項（名稱、濃度、甜度、氣泡、顏色） | `BASES`、`MIXERS`、`ACCENTS` |
| 酒譜（組合、比例、口感、標籤） | `RECIPES` |
| 像素圖樣（16x16） | `SPRITES` |
| 轉盤預設選項 | `WHEEL_DEFAULTS` |
| 遊戲題庫 | `HOT_POTATO_TOPICS`、`KINGS_CUP_RULES`、`TRUTHS`、`DARES`、`NEVER_HAVE_I_EVER`、`SPY_WORDS` |

酒譜裡的品名要和轉輪品項的名稱一致，打錯字時瀏覽器 console 會報錯。

酒譜整理自網路上的超商調酒文章，標「創意」的是自己搭的。各門市進貨不同，大店品項比較齊。
