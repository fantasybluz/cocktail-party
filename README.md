# 超商調酒拉霸機 cocktail-party

像素風的聚會小工具，用 React + TypeScript + Vite 寫成靜態網站，放在 Cloudflare Pages。
底部切換兩個頁面：

- **調酒拉霸機**：三個轉輪「基酒、材料一、材料二」，品項都是超商（以 7-11 為主）買得到的東西。
  每次轉出一杯現成酒譜，附上比例、口感，以及估算的酒感、甜度、氣泡
  - **惡魔開關**：打開後機台變暗紅色，只轉出高濃度組合（估算約 19～26%）。基酒只剩 35% 以上的烈酒，
    第三個轉輪改成「加烈」再加一份烈酒，材料一多了啤酒。酒譜參考網路上「後勁強、容易醉」的調酒
    （長島冰茶、野格炸彈、深水炸彈、氣泡烈酒），每杯都寫了容易醉的原因；1 份以 shot 杯（30ml）計
- **喝酒遊戲**：20 種一支手機大家輪流操作的遊戲，加上 3 個聚會工具（記分板、派對結算、分組點名）；輸了可以直接「去轉拉霸機」決定喝什麼，
  或按「記一杯」記到記分板

網址：https://drunk.bluz.dev/ （舊網址 https://fantasybluz.github.io/cocktail-party/ 會自動轉過來，`#頁面` 也會帶著）
把網址貼到 LINE 聊天室，大家點了會直接在 LINE 內建瀏覽器打開。

## 在家玩：要先準備什麼

拉霸機轉出來的酒譜，品項都是超商買得到的。不用全部買齊，照人數挑一組就好；
沒買到的品項可以在拉霸機上**鎖定家裡有的酒**，只轉那支酒的酒譜。
這些內容在 App 裡也看得到：拉霸機招牌右上角的 **[?]**（`#guide`），各組能做哪幾杯是依酒譜即時算的。

### 照人數挑一組

下面是用酒譜資料算出來「買最少、能做最多杯」的組合（都要再加冰塊）：

| 組合 | 酒 | 飲料 | 能做的酒譜 |
|---|---|---|---|
| **小酌組**（2～3 人） | 威士忌、梅酒 | 氣泡水、可樂、黑松沙士、無糖綠茶 | 6 杯：嗨棒、威士忌可樂、威士忌綠茶、威士忌沙士、梅酒蘇打、梅子綠茶 |
| **派對組**（4～6 人） | 威士忌、伏特加、琴酒、梅酒 | 氣泡水、可樂、雪碧、黑松沙士、無糖綠茶、冬瓜茶、柳橙汁 | 11 杯：小酌組＋威士忌冬瓜茶、螺絲起子、琴雪通、琴酒柳橙、琴酒綠茶 |
| **大派對組**（6 人以上） | 威士忌、伏特加、琴酒、高粱、燒酒 | 氣泡水、可樂、雪碧、黑松沙士、無糖綠茶、柳橙汁、冰結葡萄、養樂多 | 13 杯：嗨棒、威士忌可樂、威士忌綠茶、威士忌沙士、螺絲起子、養樂多伏特加、琴雪通、琴酒柳橙、琴酒綠茶、養樂多高粱、高粱葡萄冰結、養樂多燒酒、葡萄燒酒 |

全部 27 杯都要做的話，就是下面清單全買。

### 完整清單（括號是用在幾杯酒譜）

- **基酒**：威士忌（6）、伏特加（6）、琴酒（4）、燒酒（3）、高粱（2）、野格（2）、清酒（2）、梅酒（2）
- **材料一**：氣泡水（6）、雪碧（4）、無糖綠茶（3）、可樂（2）、黑松沙士（2）、柳橙汁（2）、冰結葡萄（2）、
  蘋果西打、冬瓜茶、蔓越莓汁、草莓牛奶、紅牛、冰結檸檬（各 1）
- **材料二**：冰塊（19，一定要買）、養樂多（3）、可爾必思（2）、檸檬棒棒冰（2）、香草冰淇淋（1）

只想買一支酒的話，威士忌最划算：配氣泡水、可樂、黑松沙士、無糖綠茶、冬瓜茶和冰塊，
就能做嗨棒、威士忌可樂、威士忌沙士、威士忌綠茶、威士忌冬瓜茶 5 杯，再加香草冰淇淋還有威士忌可樂漂浮。

### 份量怎麼抓

- 一般模式 **1 份 ≈ 一瓶 50ml 迷你酒**，常見比例是酒 1：飲料 3，也就是 50ml 酒配 150ml 飲料
- 一個人一晚抓 2～3 杯：4 個人大約 8～12 份酒，買迷你瓶就是 8～12 瓶，或一支 700ml 的酒（約 14 份）
- 飲料：600ml 寶特瓶大約可以調 4 杯、一罐 330ml 大約 2 杯
- 冰塊：19 杯酒譜都要先裝滿一杯冰，寧可多買；冰淇淋、棒棒冰記得放冷凍

### 器具

- 每人一個杯子、量酒用的量杯或 shot 杯（30ml／50ml）、攪拌用的長湯匙或吸管
- 剪刀（剪棒棒冰）、冰淇淋挖勺（威士忌可樂漂浮）
- 喝酒遊戲大多只要手機；國王杯要在中間放一個空杯當國王杯

### 惡魔模式另外要準備

- **啤酒**（深水炸彈、高粱炸彈）和 **shot 杯**
- 惡魔模式 **1 份 = 一個 shot 杯（30ml）**，而且每杯都有兩份烈酒（基酒＋加烈）
- 當基酒的：伏特加、高粱（各 4 杯）、威士忌（3）、野格（2）、琴酒（1）；加烈的 shot 這五種各用在 2～3 杯
- 飲料用得最多的是可樂、紅牛、啤酒（各 2 杯）

### 喝之前

- 準備水和食物，不要空腹喝；記分板每 3 杯會提醒喝水
- 先安排好回家方式，**喝了就不開車**
- 未滿 18 歲不要喝；不舒服就停，不用勉強玩完

## 喝酒遊戲

| 遊戲 | 玩法 |
|---|---|
| 懲罰轉盤 | 跑燈停在哪格就照做，八格選項可以自己改 |
| 數字炸彈 | 炸彈藏在 1～100，輪流猜，範圍越縮越小，猜中的人喝 |
| 開箱炸彈 | 箱子裡藏炸彈（箱子、炸彈數可調），開到的人喝 |
| 傳手機炸彈 | 隨機倒數，說出符合題目的答案再傳下去，爆炸時拿著的人喝 |
| 國王杯 | 抽牌照規則做，第四張 K 的人喝光國王杯 |
| 真心話大冒險 | 抽題目，做到按「挑戰成功」換下一個人，按「挑戰失敗」跳出「誰喝一杯？」 |
| 我從來沒有 | 做過題目上那件事的人喝 |
| 誰是臥底 | 傳手機看詞，描述後投票，找出拿到不同詞的人 |
| 命運手指 | 大家同時放一根手指在螢幕上，亮起的那根喝（多點觸控；iPhone 約 5 根） |
| 頭上猜詞 | 手機貼額頭，其他人比手畫腳；點頭答對、抬頭跳過（也能點螢幕） |
| 你畫我猜 | 64x64 的像素畫布，時間到沒人猜中畫的人喝 |
| 吹牛骰 | 傳手機偷看自己的骰子，喊數量，按「開！」一次公布全部骰子（可選 1 點萬用） |
| 猜高低 | 猜下一張牌大或小，猜錯喝掉累積的口數 |
| 喝酒大富翁 | 24 格棋盤擲骰子走，格子會串到真心話、拉霸機、誰最可能等 |
| 誰最可能 | 3、2、1 一起指，被指最多的人喝 |
| 兩真一假 | 照主題說三件事，大家猜哪件是假的 |
| 停在 10 秒 | 輪流按碼表，覺得剛好 5／10／15 秒就停；離目標最遠的人喝，差不到 0.1 秒是神手（可選前 3 秒看得到或全盲） |
| 反應力大考驗 | 畫面變紅後等綠燈，一變綠就按；最慢的人喝，偷跑算犯規也喝 |
| 記憶挑戰 | 手機依序閃四色燈號，輪到的人照順序按，答對傳下去並多一步；按錯的人喝，會記最高紀錄 |
| 瘋狂海盜桶 | 桶子有 12／18／24 個洞，輪流選一洞插劍，插到機關海盜跳出來的人喝 |

聚會工具：

- **喝酒記分板**：記每個人喝幾杯，每 3 杯提醒喝水；名單存在手機裡，吹牛骰、大富翁、誰是臥底會用名單上的名字。
  每個遊戲頁右上角都有「記一杯」，要喝的時刻也有專屬按鈕；選人時可以連點、大家都 +1、復原，名單是空的也能直接新增
- **派對結算**：從記分板按「派對結算」或在聚會工具打開。統計今晚總杯數、時間，頒發今晚酒王、炸彈磁鐵、
  挑戰失敗王、最衰、喝水模範生、第一杯、最清醒；每個人的杯數長條圖、最多人喝的遊戲、最熱鬧的時段。
  可以存成像素風圖片或分享文字到 LINE；「開新的一場」會把杯數和紀錄歸零、保留名單
- **分組點名**：隨機點名、排順序、分 2～4 隊

**分享圖**：拉霸機酒譜卡、遊戲結果、派對結算都可以「存成圖片」（canvas 畫的像素風圖，附網址和
「禁止酒駕・飲酒過量，有害健康」）。手機支援的話直接開分享選單，不支援（例如 LINE 內建瀏覽器）就顯示圖片讓你長按儲存。

每記一杯都會留一筆紀錄（誰、什麼時候、哪個遊戲、原因：炸彈／挑戰失敗／遊戲輸了／拉霸機／其他），
存在這支手機的 localStorage，派對結算從這裡算。

**成人題庫（18+）**：遊戲列表上方的開關，打開前要確認大家都滿 18 歲。真心話大冒險、我從來沒有、誰最可能、
兩真一假會改用感情、曖昧類的題目；碰到別人的大冒險都要對方同意，不想做一樣喝一杯跳過。

- 頁面用網址的 `#` 切換（例如 `#spy`），LINE 和瀏覽器的上一頁也能用
- 跟時間、手指有關的遊戲（懲罰轉盤、傳手機炸彈、命運手指、頭上猜詞、你畫我猜、停在 10 秒、反應力大考驗、記憶挑戰、瘋狂海盜桶）離開頁面就停止；其他遊戲切走再回來會保留進度

酒譜整理自網路上的超商調酒文章，標「創意」的是自己搭的。各門市進貨不同，大店品項比較齊。

頁尾的「你是第 N 個酒鬼」是 [GoatCounter](https://www.goatcounter.com) 記的瀏覽人數（有最多四小時的快取，是大概的數字）。

## 開發

```bash
npm install
npm run dev        # http://localhost:5173/
npm test           # 單元測試 + 文件檢查
npm run lint && npm run lint:css
npm run build      # 型別檢查 + 建置到 dist/
```

推到 `main` 會由 GitHub Actions 檢查後部署到 Cloudflare Pages，舊的 GitHub Pages 網址只放轉址頁；
設定和 secret 見 [docs/setup.md](docs/setup.md)。發版見 [RELEASING.md](RELEASING.md)。
