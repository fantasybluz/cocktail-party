# 0001 從單一 HTML 檔改成 React + TypeScript + Vite，沒有後端

- 狀態：採用
- 日期：2026-10-12

## 背景

第一版（`1b2a475`）是一個 `index.html`，樣式、程式、Cubic 11 字型全部塞在裡面：三個轉輪、27 杯酒譜、分享到 LINE。
同一天加了喝酒遊戲頁（8 個遊戲），之後還要加更多遊戲和題庫，一個檔案越來越難改，而且酒譜、題庫打錯字沒有東西會擋。

## 決定

用 React + TypeScript + Vite 重寫成靜態網站（`7411e46`，0.3.0），畫面和行為跟原本一樣：

- 資料（品項、酒譜、像素圖樣、題庫）變成有型別的模組（`src/data/`、`src/lib/sprites.ts`）
- 一個遊戲一個元件，規則邏輯拆成純函式，用 Vitest 測：
  酒譜的品名打錯、圖樣不是 16×16、用到沒定義的顏色、題目重複都會失敗
- 遊戲共用的動作（輸家去轉拉霸機、跳到真心話大冒險、爆炸畫面，之後加了記一杯）放在 `PartyContext`
- ESLint、Stylelint 的設定跟 fantasybluz.github.io 一樣
- **沒有後端**：一支手機大家輪流用，記分板、紀錄存 localStorage，不用登入、不用連網路也能玩

## 代價

- 要建置才能看（`npm run build`），不能直接打開 HTML 檔
- 資料只在一支手機上：換手機、清瀏覽器資料，名單和紀錄就沒了；沒辦法多支手機一起記
- 重寫時 localStorage 的 key 沿用最早的 `mix-slot-` 開頭，之後也不能改
